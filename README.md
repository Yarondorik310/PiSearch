# PiSearch
(ПОКА ТОЛЬКО НА РУССКОМ!)
Программа для поиска цифр или букв в числе π!


--- Как установить:

-- 1. Скачайте файл PiSearch.exe с вкладки релизов или PiSearch.exe с исходного кода.

-- 2. Скачайте библиотеки (инструкция по скачиванию библиотек после этой).

-- 3. Запускайте и пользуйтесь!


--- Про библиотеки:

-- Группа - это библиотеки, относящиеся к определённому количеству знаков после запятой числа π.

-- Вы ДОЛЖНЫ скачать библиотеку dig.pi из любой группы. Выбирайте, из какой скачать: 1 000 000 - не требует много места; 100 000 000 - требует достаточно места; 1 000 000 000 - требует много места (количество знаков после запятой числа π, принадлежащее этой группе, и является её названием).

-- Теперь по желанию скачивайте ИЗ ЭТОЙ ЖЕ ГРУППЫ другие библиотеки, благодаря которым вы сможете искать в числе π буквы!
