# PiSearch
(ПОКА ТОЛЬКО НА РУССКОМ!)
Программа для поиска цифр или букв в числе π!


Установить программу с библиотеками и узнать про неё побольше можно на её официальном сайте: https://yarondorik.itch.io/pisearch. Здесь только исходник файла PiSearch.exe и самые маловесящие библиотеки для удобства.
